# 🎮 GamesHub – Flutter Gaming App

**GamesHub** is a modern multi-game Flutter application built using a **freemium model**, featuring a **Pro subscription system**, smooth animations, and offline gameplay support.  
This project demonstrates real-world Flutter app architecture, UI/UX design, and feature-locking logic.


---

## 🚀 Features
- 🎮 **9+ Mini Games** (Free & Pro categories)
- 🔓 **Freemium Model** – Free games with optional Pro upgrade
- 🔐 **Firebase Authentication** – Secure email login & registration
- 💳 **Pro Subscription System** – Payment integration *(Demo)*
- 🎨 **Modern Dark UI** – Gradient-based Material Design
- ⚡ **Offline Gameplay** – Play games without internet
- ☁️ **Cloud Sync** – Save progress using Firebase

---

## 🎯 Games Included

### 🆓 Free Games
1. **Tic Tac Toe** 🎯 – Classic X vs O with AI opponent  
2. **Memory Match** 🧠 – Card-matching puzzle with increasing difficulty  
3. **Math Dash** ➗ – Fast-paced educational arithmetic game  
4. **Chess** ♟️ – Strategy board game vs AI  
5. **Avoid Blocks** 🚫 – Reflex-based obstacle dodging game  

### 💎 Pro Games *(Subscription Required)*
6. **Snake Game** 🐍 – Classic snake gameplay with power-ups  
7. **2048 Pro** 🔢 – Advanced number-merging puzzle  
8. **Water Sort** 🌊 – Logic-based color sorting puzzle  

---

## 🛠 Tech Stack
- **Frontend:** Flutter (Dart)
- **Backend:** Firebase (Authentication, Firestore)
- **Database:** Cloud Firestore
- **Payments:** Demo Mode
- **State Management:** Provider & setState
- **Version Control:** Git & GitHub
